Gesture MP3 Player

2025

An MP3 player on an Arduino Uno, with a DFPlayer Mini pulling tracks off a microSD card. Buttons handle the obvious controls and an ultrasonic sensor handles the rest — wave a hand to play, pause or skip — with an LED flashing along to whatever's going. Built for the IoT module, and wired up in Tinkercad first, because breadboarding blind is a bad time.

  • Arduino
  • C++
  • DFPlayer
  • Ultrasonic
